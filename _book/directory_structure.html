2  Data and Directory Structure

This chapter primarily exists to guide other members of the working group in modifying, updating, or extracting information from this book.

2.1 Directory organization

  • _quarto.yml is the main ‘table of contents’ of all .qmd files in order. Each chapter also has an ‘About’ section at the bottom identifying the exact file used to generate it, as well as details about the input and output datasets for the chapter.
  • _book/ is the subfolder with output files. Open any .html in here and you’ll have access to the full structure. The pdf output is also in this directory.

2.2 Data, data, data

  • data/raw = time series, unmodified
  • data/intermediate = time series with some simplifications for reporting and summarizing; generally outputs from the “Data Exploration” chapters of this book
  • data/processed - combined data: abundance summarized to abundance index, plus environmental metrics for each shrimp year. Separate files for brown and white shrimp. Folders contain individual pieces that contributed to these final main files, plus additional detail.
  • byLifeStage - single file for each life stage, summarized to shrimp year, and usually containing both species. The species have separate files for the ‘landings’ life stage due to different temporal resolution of input data. This folder has a sub-folder, moreDetailed, in which different sampling levels - month, state/region, etc. - are retained.
  • combinedLifeStages - contains a single file, with abundance index calculated for each life stage of both species of shrimp. This was one of the building blocks to the files in the main processed directory.
  • environmental - contains a file for each species, with summarized nursery period salinities and winter temperatures.

2.3 Main Files

There are two main data files: one for each species. Each file combines abundance information with environmental information. They are in the folder data/processed. Each files contains one row for each shrimp_year x life_stage combination, meaning environmental data is replicated several times for each shrimp_year. This was done on purpose to make future data selection easier on users; but if you want a single row of environmental data per shrimp year, use the file in the data/processed/environmental directory.

Brown Shrimp combined file

brn_abundAndEnv.csv, in data/processed.

Columns are:

  • survey - which data set or combination of datasets was used for this life stage
  • species - brown or white; all ‘brown’ in this file
  • life_stage - life stage of the shrimp
  • shrimp_year - shrimp year for which the information applies. This file contains one row for every life stage for every shrimp year. Note, nursery period and winter metrics will be the same for each life stage in the same shrimp year.
  • abundance_measure - the metric originally used as “abundance” (e.g. density, count, weight)
  • abundance - the total, for the shrimp year, of monthly abundances (see the data processing chapters for detail)
  • sqrt_abundance - square root of abundance; this is the value that was normalized for each life stage in order to calculate abundance index.
  • abundanceIndex_fullTimePeriod: abundance index as calculated/normalized for the entire time series of the life stage.
  • abundanceIndex_commonTimePeriod: abundance index as calculated/normalized across only the shrimp years years that are common to all life stages (1989-2017).
  • nursery_sal.CH07 / .CH09 / .CH10 / .CH18 / .mean07.09.10: nursery period salinity for each shrimp year at different sampling stations in Charleston Harbor, from SCDNR’s monthly sampling. Stations used are CH07, CH09, CH10, and CH18. During data exploration, CH18 showed fairly different patterns than the other stations, so was excluded from a mean between stations CH07, CH09, and CH10 for each month. These individual stations and the mean are all provided because we did not get to a stage of determining which would best represent nursery period salinity conditions. For brown shrimp, the nursery period was defined as the months of April through July.
  • winter_wTemp.CHS_min / mean / median / max / p25 / p75 / sd / iqr: for each shrimp year, winter (December, January, and February) water temperatures at the Charleston Harbor NOAA station were compiled and summarized. Min, mean, median, and max are self-explanatory. p25 is the 25th percentile (1st quantile); p75 is the 75th percentile (3rd quantile); sd is standard deviaion; iqr is interquartile range.
  • totalDays_lessThan7 / 8 / 9 / 10 … / 16: for each shrimp year, the total number of days in winter (December, January, and February) where the daily mean water temperature reported by the Charleston Harbor NOAA station was below the threshold X degrees Celsius, where the number at the end of the column name is X.
  • totalSpells_lessThan7 / 8 / … / 16: a “cold spell” was defined as a period of 7 or more consecutive days in winter (December, January, and February) where the average water temperature at the Charleston Harbor NOAA station was below the threshold X degrees Celsius, where the number at the end of the column name is X.
  • longestSpell_lessThan7 / 8 / … / 16: the number of days that the longest “cold spell” in a winter lasted, where “cold spell” is defined as a period of 7 or more consecutive days where the average water temperature at the Charleston Harbor NOAA station was below the threshold X degrees Celsius, where the number at the end of the column name is X.

White Shrimp combined file

wht_abundAndEnv.csv, in data/processed.

Columns are generally the same as for brown shrimp, BUT white shrimp lives can span two winters - so there are two columns for each winter metric. These columns start with either postlarvWinter, the shrimps’ first winter; or subadultWinter, the winter in which shrimp will be subadults to adults. Fishery managers are more interested in subadultWinter because these are the cold spells that cause the fishery to close. postlarvWinter was calculated as well in case future investigators want to look at effects of cold on the younger life stages.

In addition to the temperature metrics for both winters, there is a column identifying which calendar year those metrics were summarized from: postlarvWinter_ / subadultWinter_calendar_year. Example: for shrimp year 1981, the calendar year 1981 winter (December 1980 through February 1981) corresponds to postlarvWinter, and calendar year 1982 winter (December 1981 through February 1982) corresponds to subadultWinter. Calendar year 1982 winter will be postlarvWinter for shrimp year 1982. So, there is much repetitive information in these files, but I have tried to be very explicit about each piece of information represents and how it relates to the shrimp.

The other difference between files is a different nursery period. The calculations and column meanings are the same, but the applicable nursery period for white shrimp is June through October.
